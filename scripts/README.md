# Scripts

Futuros importador idempotente do catálogo local, verificador de domínios/links e conferência de limite de funções/payload. Não executar importação ou deploy automaticamente.

Para conferir as páginas de amostra sem usar credenciais locais, inicie `powershell -NoProfile -File scripts/dev-demo.ps1`. O processo define `PUBLIC_CATALOG_DEMO=true`, desativa leitura do catálogo/autenticação e bloqueia saída de compra e exclusão remota. Encerre com `Ctrl+C`.
